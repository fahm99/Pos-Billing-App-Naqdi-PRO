# خطة تحويل "نقدي" إلى نظام محاسبي متكامل

## نظرة عامة على النموذج التجاري

تطبيق "نقدي" يعتمد على نموذج **Freemium** حيث:
- **الباقة المجانية (Free):** نظام نقاط بيع (POS) كامل للمحلات والبقالات
- **الباقة المميزة (Premium):** نظام محاسبي متكامل مع جميع الميزات المتقدمة

---

## الفلسفة التجارية

### لماذا Freemium؟
1. **جذب المستخدمين:** تقديم قيمة مجانية لبناء قاعدة مستخدمين
2. **التحويل الطبيعي:** المستخدمون الذين يعتمدون على التطبيق سيدفعون للميزات المتقدمة
3. **الإيرادات المتكررة:** اشتراكات شهرية/سنوية توفر تدفق نقدي مستقر
4. **ميزة تنافسية:** معظم التطبيقات المحاسبية要么 مجانية بالكامل أو مكلفة جداً

---

## هيكل الاشتراكات المقترح

### Option A: اشتراك واحد شامل (موصى به)
```
المجاني: 0 ريال
المميز: 199 ريال/شهرياً أو 1,990 ريال/سنوياً (وفر 20%)
```

### Option B: مستويات متدرجة
```
المستوى 1 (أساسي): 99 ريال/شهرياً
المستوى 2 (متوسط): 199 ريال/شهرياً
المستوى 3 (متقدم): 299 ريال/شهرياً
المستوى 4 (كامل): 499 ريال/شهرياً
```

### Option C: Bundle (أفضل قيمة)
```
الاشتراك السنوي الشامل: 1,490 ريال (وفر 40%)
```

## استراتيجية الإطلاق

### المرحلة الأولى: الإطلاق المجاني
- إطلاق الإصدار المجاني
- جمع ملاحظات المستخدمين
- تحسين الأداء والثبات

### المرحلة الثانية: إطلاق الباقة المميزة
- تقديم تجربة مجانية 14 يوم
- عرض القيمة المضافة للميزات المميزة
- تقديم خصم الإطلاق (30%)

### المرحلة الثالثة: التوسع
- إضافة طرق دفع متنوعة
- شراكات مع محاسبين ومؤسسات
- تسويق موجّه للمحلات والبقالات

## مقاييس النجاح

### مقاييس النمو
- **عدد المستخدمين:** الهدف 1,000 مستخدم في الشهر الأول
- **معدل التحويل:** الهدف 5% من المجانيين للمميز
- **معدل الاحتفاظ:** الهدف 80% بعد 3 أشهر

### مقاييس الإيرادات
- **ARPU (متوسط الإيراد لكل مستخدم):** الهدف 50 ريال/شهر
- **LTV (قيمة العمر الافتراضي):** الهدف 600 ريال
- **CAC (تكلفة اكتساب العميل):** أقل من 100 ريال
